# 🧩 Sudoku Solver using CSP (AI Assignment)

This project implements a **Sudoku Solver** using **Constraint Satisfaction Problem (CSP)** techniques.

## 🚀 Techniques Used

* Backtracking Search
* Forward Checking
* AC-3 Algorithm (Arc Consistency)
* MRV Heuristic (Minimum Remaining Values)

## ▶️ How to Run

```bash
python solver.py
```

## 📥 Input Format

Each Sudoku file should contain 9 lines with 9 digits:

Example:

```
530070000
600195000
098000060
```
